# «Тропа» — аренда туристического снаряжения

Многостраничный интерфейс проката на HTML5, CSS3, JavaScript и Bootstrap 5.3.8.

## Запуск

Распакуйте архив и откройте `index.html` в папке `tropa`. Node.js и сборка не требуются. Для загрузки Bootstrap с CDN нужен интернет. Для общего сохранения корзины, избранного и темы между страницами рекомендуем VS Code → Live Server. При установленном Python на Windows можно запустить start-site.bat и открыть http://127.0.0.1:8000. Локальные стили и запасные обработчики меню, вкладок и FAQ обеспечивают работу основных элементов без CDN.

## Страницы и файлы

`index.html` — главная. `catalog.html` — каталог с поиском, фильтрами и сортировкой. `equipment.html?id=taiga-2` — карточка выбранного предмета и калькулятор. `blog.html` — «С чего начать?», пошаговый гид для первого похода с интерактивной памяткой вещей. `contacts.html` — контактные данные, предварительный расчёт и FAQ.

`css/custom.css` содержит оформление. `js/products.js` — сведения о шести предметах. `js/app.js` — фильтры, расчёт, валидацию и обработку параметров URL. В папке `images` находятся локальные SVG.

## Подвал

Три колонки: бренд и описание, навигация, адрес самовывоза с телефоном, компактным графиком и электронной почтой. Первая ссылка в навигации — «С чего начать?». Кнопки MAX и Telegram находятся в колонке «Самовывоз и контакты» под электронной почтой. В колонке «Собираемся в поход» остаются только ссылки на гид, каталог и описание аренды; «Контакты» остаются в верхнем меню. Строка «© 2026 „Тропа“. Все права защищены» отделена от описания. Отдельная нижняя служебная полоса отсутствует. Ссылки и раздел с условиями проката удалены.

## Контакты перед публикацией

По запросу владельца для макета выбраны вымышленные контактные реквизиты: Москва, ул. Лесная, д. 12; +7 (800) 123-45-67. Номер изменён по запросу владельца; его принадлежность не проверена, он не является подтверждённым контактом проката. Адрес не означает наличие реального пункта проката. Почта hello@tropa.example также не является действующим ящиком. Перед публикацией замените реквизиты в подвале всех пяти страниц и на странице contacts.html.

## Расчёт

Цена за сутки умножается на разницу календарных дат и количество. Минимум — одни сутки. Залог рассчитывается отдельно. Прошедшие даты и возврат раньше получения недопустимы.

## Серверная часть

Текущая форма выполняет локальный расчёт, не отправляет контакты, не резервирует инвентарь и не принимает платежи. Контактные поля необязательны. После расчёта предлагается связаться с пунктом проката; сообщения об отправке заявки нет. Для приёма заявок нужно подключить сервер, проверку наличия и обработку данных. До этого не следует менять кнопку на «Отправить заявку» или показывать подтверждение бронирования.

## Доступность

Адаптивная сетка, мобильное меню, подписи полей и иллюстраций, хлебные крошки, ссылка пропуска навигации, видимый фокус и поддержка prefers-reduced-motion.

## Мессенджеры

Кнопки MAX и Telegram расположены в контактной колонке подвала всех пяти страниц, непосредственно под почтой. Сейчас они ведут на https://max.ru/ и https://t.me/ — главные страницы сервисов, а не аккаунты проката. Чтобы подключить связь с компанией, замените href соответствующих кнопок на настоящие ссылки во всех пяти HTML-файлах. Кнопки открываются в новой вкладке с rel="noopener noreferrer"; иконки встроены в HTML и не требуют внешних библиотек.


## Тема, корзина, избранное и консультант

`js/theme-init.js` применяет сохранённую светлую или тёмную тему до отрисовки страницы. Если тема ещё не выбрана, учитывается системная настройка. Кнопка в шапке переключает её вручную. `css/features.css` содержит оформление обеих тем и новых интерфейсов.

`js/store.js` хранит корзину, избранное и общие даты аренды в localStorage под ключом `tropa.shop`. Тема — под ключом `tropa.theme`. Контактные данные из формы и сообщения консультанту не сохраняются. Если браузер запрещает localStorage, элементы продолжают работать на открытой странице, но после перехода между HTML-файлами состояние может не сохраниться. Для надёжного хранения при разработке используйте Live Server или другой локальный HTTP-сервер; поведение localStorage на file:// зависит от браузера.

В корзине можно изменить количество (1–5 единиц каждого предмета), удалить позицию, очистить список и выбрать общие даты для всех вещей. Итог — сумма суточных цен × срок, залог отображается отдельно. Кнопка «Перейти к расчёту комплекта» открывает `contacts.html?cart=1#order`; форма рассчитывает все позиции корзины. Даты передаются через сохранённое состояние. Расчёт не подтверждает наличие и не создаёт бронирование.

Сердечки на карточках и странице снаряжения добавляют предметы в избранное. В избранном можно убрать вещь или добавить её в корзину. Счётчики в шапке обновляются сразу, включая синхронизацию открытых вкладок одного сайта.

`js/features.js` управляет панелями, темой и консультантом. Боковые панели используют native dialog: модальная подложка, закрытие по Escape и клавиатурный фокус. Виджет «Консультант „Тропы“» — локальный автопомощник с готовыми ответами по ключевым словам. Он не подключён к человеку или ИИ-сервису, не отправляет переписку и не проверяет склад. Для нестандартных вопросов предлагается обратиться в пункт проката.

На странице контактов есть те же MAX и Telegram с иконками, что и в подвале; телефон и почта снабжены иконками. Почта располагается до графика. На странице «С чего начать?» каждому из пяти шагов соответствует отдельная локальная SVG-иллюстрация.


## Визуальные корректировки

Кнопка возврата к началу страницы содержит только SVG-палатку, согласована с обеими темами и находится в правом нижнем углу. Консультант и окно переписки расположены в левом нижнем углу. Клавиатурный фокус и настройка уменьшения анимации сохранены.

Иллюстрация на странице контактов размещена в отдельной рамке pickup-scenery. Изображение сохраняет исходные пропорции 760:620, имеет автоматическую высоту и показывается целиком вместо обрезки object-fit: cover в полосу высотой 130 пикселей.


Переключение темы выполняется с наплывом около 0,9 секунды через View Transition API; в браузерах без него предусмотрен плавный CSS-переход цветов. При prefers-reduced-motion тема переключается без анимации. Первая загрузка не анимируется, выбор темы по-прежнему сохраняется.


## Вечер в горах

На главной странице кнопка «Вечер в горах» плавно меняет дневную иллюстрацию на ночную за 1,4 секунды: появляются луна, звёзды и тёплый свет в палатке. Повторное нажатие возвращает день. Эффект не меняет тему сайта, не использует внешние сервисы и не сохраняет состояние. При включённом сокращении движения в системе переход происходит без анимации. Кнопка работает с клавиатуры и появляется только после загрузки ночного изображения; без JavaScript остаётся дневная иллюстрация. Код эффекта: css/camp-effect.css, js/camp-effect.js; ночная иллюстрация: images/camp-night.svg.
